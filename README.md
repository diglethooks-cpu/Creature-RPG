# Wildlight — Creature RPG

An original creature-collecting adventure designed for desktop and mobile browsers.

## Core experience
- Explore connected regions with keyboard and touch controls.
- Discover, befriend, and train original creatures.
- Battle with a turn-based combat system.
- Meet characters, complete quests, and uncover hidden paths.
- Build a party, manage items, and save progress.

## Planned first regions
- Sunmeadow Village
- Goldenleaf Meadow
- Whisperwood
- Stillwater Lake
- Frostpeak Pass

## Development
This repository is the home of Wildlight. Features will be marked complete only after implementation and testing.
